# Data dictionary

| Field | Description | Notes |
|---|---|---|
| record_id | Synthetic unique row identifier | Not a real-world identifier |
| event_time | Synthetic event timestamp | UTC-naive demo timestamp |
| city | Synthetic Indian city label | Not precise geolocation |
| segment | Synthetic business/customer segment | Illustrative categories |
| category | Synthetic product/service category | Illustrative categories |
| amount | Synthetic numeric value in INR-like units | Not actual transactions |
| target fields | Task-specific outcome/label | Synthetic labels only |
